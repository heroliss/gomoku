# 更新记录

## 3.1.0

- 黑白各自选择 11 种引擎之一，并独立设置深度 1–8、250–10,000 ms 每步预算和评估函数；设置与棋谱分开保存。
- 新增独立“统计”页：当前棋谱前缀内已落子 AI 决策的次数、最近/累计/平均墙钟耗时、累计节点/命中和最近完成深度。提示、取消、人工/联机落子不计；回看、悔棋/重做同步汇总，新局或读档清空测量。
- 新增单方 `--black-*` / `--white-*` 参数，以及 `--page stats`、`--empty-showcase`、`--autoplay-plies N`，保留原有共同参数。示例见 README。
- 保留全部经典搜索代码路径和 V3 威胁搜索。搜索通过后台工作线程运行，内部仍为单线程；不将墙钟统计解释为 CPU 利用或并行加速。
