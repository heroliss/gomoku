# 更新记录

## 3.2.0

- 首次进入联机页自动连接一次；创建或加入自动等待连接就绪，不再要求先手动连接。主动断开后不反复自动重连，失败可重试。
- 明确展示连接、建房、入房、等待、对局及退出等阶段，并提供对应的取消、断开和返回大厅操作。网络连接与房间操作各有 30 秒超时，房内等待对手除外。
- 房间列表显示人数，空列表提供下一步指引；大厅内可改昵称，房内显示双方身份和等待状态。
- 建房、入房、房内等待和退房时禁止本地 AI、悔棋、读档及回放等冲突操作；联机中按 Esc 不再误报“已暂停”。保存使用开始选择文件时的棋局快照。
- 沿用 `liss-gomoku-v3` 协议，与 3.0/3.1 的同协议客户端兼容。断线不续接原对局，保留本地棋谱。

## 3.1.0

- 黑白各自选择 11 种引擎之一，并独立设置深度 1–8、250–10,000 ms 每步预算和评估函数；设置与棋谱分开保存。
- 新增独立“统计”页：当前棋谱前缀内已落子 AI 决策的次数、最近/累计/平均墙钟耗时、累计节点/命中和最近完成深度。提示、取消、人工/联机落子不计；回看、悔棋/重做同步汇总，新局或读档清空测量。
- 新增单方 `--black-*` / `--white-*` 参数，以及 `--page stats`、`--empty-showcase`、`--autoplay-plies N`，保留原有共同参数。示例见 README。
- 保留全部经典搜索代码路径和 V3 威胁搜索。搜索通过后台工作线程运行，内部仍为单线程；不将墙钟统计解释为 CPU 利用或并行加速。

## 3.0.0

基于找回的 v2.3 源码现代化：11 种引擎、深色棋盘、人机/双人/引擎对弈、V3 Photon 房间、JSON/SGF 棋谱和后台取消。原始 v2.5 源码未找回，不声称恢复其全部实现。
